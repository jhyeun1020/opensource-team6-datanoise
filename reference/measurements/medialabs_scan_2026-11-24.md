# 미디어랩스 스캔 실측값 (2026-11-24)

팀원이 iPhone Pro + Polycam 공간 모드로 찍은 스캔(GLB)에서 잰 값이다.
스캔 원본은 용량(약 30MB)과 공개 저장소 문제로 Git에 올리지 않는다. 팀 단톡방에서 받아 `reference/scans/` 에 넣으면 된다.

## 스캔 범위

긴 복도 하나와 거기 붙은 방 두 개.

| 구역 | 안쪽 크기 | 비고 |
|---|---|---|
| 복도 | 폭 약 **2.5m**, 천장 약 **2.7m**, 스캔된 길이 약 49m | 한쪽 벽에 사물함, 바닥에 노란·파란 테이프 줄 |
| 실습실 | 약 **7.5 x 14.5m**, 천장 약 2.7m | 컴퓨터 책상이 긴 방향으로 두 줄, 가운데 통로 |
| 복도 끝 방 | 약 **7 x 7.6m** | 사무실 형태 |

재는 방법: GLB 꼭짓점의 높이 분포에서 바닥·천장 면을, 벽 높이 구간만 잘라낸 평면 분포에서 벽 위치를 찾았다. 오차는 대략 ±10cm.

## 게임 맵에 반영한 값 (`scripts/level_builder.gd`)

| 항목 | 이전 | 지금 |
|---|---|---|
| 벽 높이 `WALL_H` | 4.0m | **2.7m** |
| 복도 안쪽 폭 | 3.7m | **2.5m** |
| 문 폭 `DOOR_W` | 3.0m | **2.0m** (괴물 반지름 0.5m가 지나갈 수 있는 폭) |
| 02·03 방 | 12x12m, 16x16m | **14 x 7.5m** (실습실 크기) |
| 01 입구 | 10 x 10m | **8 x 7m** (복도 끝 방 크기) |
| 랙 배치 | 방 가장자리 | 실습실 책상처럼 **두 줄, 가운데 통로 2.7m** |

배치 순서(입구 → 복도 → 방 → 복도 → 방 → 탈출)는 기획안 흐름대로 일직선이다. 실제 건물처럼 긴 복도 옆으로 방이 붙는 구조로 바꾸는 것은 별도 작업이다.

## 스캔 보기

Godot 에디터에서 `reference/scan_viewer.tscn` 을 연다. GLB를 직접 열면 검게 보인다(Polycam 파일은 조명이 텍스처에 구워져 있고 법선이 없음). 뷰어 씬은 조명 계산 없이 텍스처 색 그대로 그린다.
