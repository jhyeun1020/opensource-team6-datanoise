# 레퍼런스 자료 (미디어랩스관 현장 조사)

여기에 받은 사진·스캔·치수를 넣는다. 이 폴더는 게임에 포함되지 않고 레벨 제작 참고용이다.

## 폴더 구조

```
reference/
  photos/        현장 사진 (jpg). 파일명 규칙: 구역_번호_설명.jpg  예) 복도_01_정면.jpg
  measurements/  치수 메모·손그림 평면도 사진·스프레드시트
  scans/         3D 스캔 내보내기 (glb 권장, obj도 가능)
  audio/         현장 소리 녹음 (서버실 팬 소음, 복도 울림 등) — 있으면 좋음
```

## 꼭 필요한 것 (우선순위 순)

1. **치수 6개** — 이것만 있어도 맵을 실제 비율로 고칠 수 있다.
   - 복도 폭, 복도 천장 높이
   - 강의실/실습실 하나의 가로·세로·높이
   - 문 폭·높이, 문과 문 사이 간격
2. **손그림 평면도** — 한 층의 복도와 방 배치를 대충 그리고 위 치수를 적어 사진으로 찍은 것.
3. **사진** — 구역별 최소 3장(정면, 좌, 우). 가로 모드, 플래시 끄고, 조명 켜진 상태 그대로.
   - 복도(직선 구간, 코너, 끝), 엘리베이터 홀, 계단실, 강의실 내부, 실습실 내부
   - 디테일: 문, 안내판, 호실 표지판, 바닥 패턴, 천장 조명, 소화전, 편의점 간판
4. **3D 스캔** — 있으면 좋고 없어도 됨. Polycam / Scaniverse / Luma 로 복도 한 구간만 스캔해서 GLB 로 내보내기.

## 하지 않아도 되는 것

- 건물 전체 스캔. 게임에 나오는 공간은 복도 2개 + 방 3개다.
- 동영상. 꼭 찍었다면 중간중간 멈춰 서서 찍고, 가능하면 캡처한 정지 화면으로 보내 줄 것.

## 주의

- 연구실·실습실·서버실 내부는 관계자 허락 후 촬영.
- 다른 학생 얼굴이 나온 사진은 쓰지 않는다.
