미디어랩스: 데이터 노이즈 — 플레이 설명서
오픈소스SW 6조 / 테스트 빌드 v0.1 (2026-11-24)

────────────────────────────────────────
1. 실행 방법 (Windows 10/11, 64비트)
────────────────────────────────────────
1) 받은 zip 파일을 마우스 오른쪽 → "압축 풀기"로 폴더째 풉니다.
   (zip 안에서 바로 더블클릭하면 실행되지 않을 수 있습니다.)
2) DataNoise.exe 를 더블클릭합니다.
3) "Windows의 PC 보호" 파란 창이 뜨면
   → "추가 정보" 클릭 → "실행" 클릭.
   (서명하지 않은 학생 프로젝트라서 뜨는 경고입니다.)
4) 화면이 검게 나오거나 바로 꺼지면
   → 같은 폴더의 "그래픽 문제 시 실행.bat" 을 더블클릭하세요.
   (그래픽 카드가 오래되었거나 노트북 내장 그래픽일 때 쓰는 호환 모드입니다.)

※ Mac 은 이번 빌드에서 지원하지 않습니다.
※ 소리는 아직 없습니다. 이어폰은 필요 없습니다.

────────────────────────────────────────
2. 목표
────────────────────────────────────────
오염된 서버 노드 3개를 정제하고 미디어랩스 3층에서 탈출하세요.

  계단실에서 시작 → [E] 로 로비 문을 열고 3층으로 들어갑니다.
  ① 서버실       노드 1 정제 → 방화셔터 1 이 열리고, 괴물이 깨어납니다.
  ② ML314 강의실  노드 2 정제 → 방화셔터 2 가 열립니다.
  ③ 학회실       노드 3 정제 → 홀의 엘리베이터가 열립니다.
  엘리베이터에 들어가면 탈출 성공.

────────────────────────────────────────
3. 조작
────────────────────────────────────────
  W A S D / 방향키   이동
  Shift              달리기 (발소리가 커집니다)
  마우스             둘러보기
  F                  손전등 켜기/끄기
  E                  문 열기·닫기 / 터미널 정제 시작
  0 / 1              정제 미니게임 입력
  ESC                미니게임 중단 / 마우스 커서 꺼내기 (다시 클릭하면 돌아옴)
  R                  탈출 후 처음부터 다시

────────────────────────────────────────
4. 꼭 알아야 할 규칙
────────────────────────────────────────
■ 정제 미니게임
  - 화면에 나오는 0/1 순서를 그대로 입력하거나(순서 입력),
    잠깐 보여준 패턴을 외워서 입력합니다(패턴 대조).
  - 틀리면 큰 소리가 나고 처음부터 다시. 20초 안에 끝내야 합니다.
  - 정제하는 동안에는 손전등을 켤 수 없습니다.

■ 괴물 (글리치 교수)
  - 소리를 듣고 다가옵니다. 달리기, 문 여닫기, 터미널 조작, 오답 모두 소리입니다.
  - 손전등으로 비추면 그 자리에 굳습니다. 굳어 있는 동안에는 닿아도 죽지 않습니다.
  - 빛을 끄는 순간 빠르게 달려옵니다.
  - 얼굴 색으로 상태를 알 수 있습니다.
      보라 = 어슬렁 / 주황 = 소리 난 곳 조사 / 빨강 = 추격 / 하늘색 = 빛에 굳음
  - 닿으면 즉사. 2초 뒤 마지막으로 정제한 곳에서 다시 시작합니다.
    (정제한 노드는 그대로 남습니다.)
  - 닫힌 문 너머로는 괴물이 플레이어를 볼 수 없습니다.
    대신 괴물은 닫힌 문을 밀어젖히고 들어옵니다.

■ 손전등 배터리
  - 켜 두면 약 25초 만에 꺼집니다. 끄면 천천히 다시 찹니다.
  - 왼쪽 아래 막대가 배터리입니다.

■ 공략 힌트
  - 괴물이 복도를 막고 있으면: 빛으로 굳힌 채 옆으로 지나가거나,
    근처 방 문을 여닫아 소리로 유인한 뒤 다른 문으로 돌아가세요.
  - 강의실은 문이 2개라 앞문으로 들어가 뒷문으로 빠질 수 있습니다.
  - 방에 숨을 때는 문을 닫으세요. 닫힌 문 너머로는 괴물이 보지 못합니다.
